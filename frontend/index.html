🏆 Primary Finding — Multi-Agent Wins on Ambiguity

The multi-agent pipeline (F1 0.941) substantially outperforms the single-prompt baseline (F1 0.727) on ambiguity detection — a +0.214 margin on n=30 items. This is the novel extension the base paper (ReCompGPT) does not attempt. Ambiguity detection per ISO/IEC/IEEE 29148 is genuinely improved by the structured agent decomposition.

✅ Validated — Completeness Works in Description Mode

In the primary (description-vs-spec) operating mode, the multi-agent pipeline correctly identifies all 7 real gaps in the 10-item test set (recall = 1.000, F1 = 0.824). This validates that the architecture implements the ReCompGPT M−C method correctly when given its intended input.

⚠ Disclosed Limitation — Completeness in Spec-Only Mode

Without a paired description, the multi-agent completeness check correctly declines to speculate (F1 = 0.080, recall = 0.048). This is expected behaviour, not a bug: the ReCompGPT method is architecturally a description-vs-specification comparison. The single-prompt baseline instead draws on general world knowledge to guess at missing edge cases — which is why it wins in this specific (non-primary) operating mode. This limitation is explicitly disclosed in the paper.

🌎 Study 3 — PURE Benchmark (102 cases, LLM-as-judge corrected metric)

AgentSRS was evaluated on the same 102-case PURE dataset used by ReCompGPT. Using a corrected LLM-as-judge metric (verifying the predicted gap matches the specific removed requirement), the multi-agent pipeline achieves a 74.5% match rate vs 79.4% for the single-prompt baseline. ReCompGPT pass@1 with GPT-4o = 81.4%. The gap is explained by model size (gpt-oss-20b vs GPT-4o). Multi-agent wins on branch/conditional gaps (60% vs 55%) and hard L3 cases (50% vs 42.9%).

3 Evaluation Datasets

📊 60-Item Ablation Set

  • 30 completeness items + 30 ambiguity items
  • 3 domains: library management, e-commerce/payment, healthcare patient portal
  • ~70% defect-present for completeness; ~57% for ambiguity
  • Self-constructed following PURE dataset methodology
  • Used for: ablation comparison (multi-agent vs single-prompt)

📋 10-Item Description Set

  • 7 requirements with seeded completeness gaps
  • 3 clean controls (fully specified edge cases)
  • Each item has a paired informal description
  • Library management domain (consistent with base paper examples)
  • Used for: validating the primary description-vs-spec mode

📚 PURE Benchmark Dataset

  • 31 documents, 102 incompleteness cases (3 difficulty levels)
  • ReCompGPT reference: pass@1 = 81.4%, pass@3 = 93.8% (GPT-4o)
  • AgentSRS multi-agent match rate: 74.5% (LLM-as-judge)
  • AgentSRS single-prompt match rate: 79.4%
  • Multi-agent wins: branch gaps (60% vs 55%), hard L3 (50% vs 42.9%)
  • Source: doi.org/10.5281/zenodo.15879027

🌟 Research Positioning

  • ReCompGPT: completeness only, single-LLM pipeline
  • AgentSRS: adds ambiguity detection (novel), multi-agent pipeline
  • Base paper conclusion explicitly names "incorporating agents" as future work
  • AgentSRS ambiguity result (+0.214 F1) is the quantified novel contribution
