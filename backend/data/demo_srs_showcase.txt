The THEMAS system shall check if reported temperatures exceed set limits. Exceedances will be reported, while temperatures within limits will be output for further processing. If the temperature is below the lower limit a separate alert should be raised. Normal readings should be silently logged. || When the temperature exceeds the set limit, the system shall trigger an alarm.

A password reset option should be available. || The system shall allow a registered user to log in using a username and password.
The system shall load pages quickly so users are not kept waiting. || The system shall respond to all user interactions within an acceptable time frame.
Members can search the catalog by title or author. If nothing matches they should be told clearly so they can try a different search. Results should be sorted by relevance. || The system shall allow a member to search for a book by title or author name and display results sorted by relevance.
The system shall send a notification to the user when their borrowed book is due for return. The notification should be sent 3 days before the due date and again on the due date itself. If the book is already returned no notification should be sent. || The system shall notify the user when a book is due for return.
